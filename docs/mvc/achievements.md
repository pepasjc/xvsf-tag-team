# Marvel vs. Capcom Tag Hack: achievements

Built into the 1.0 image: an **ACHIEVEMENTS** page in the main menu, a popup when one unlocks, and progress saved
in its own memory card file. Nothing is sent anywhere; the set runs on the console.

The set is adapted from the RetroAchievements set for this game
([game 11314](https://retroachievements.org/game/11314)), by **SherryBirkin**. Every achievement keeps its goal;
the conditions were rewritten for the tag hack:

- fights are one round (the tag rules), so the "3 rounds per match" requirement is gone;
- finishes, Perfects and combos count for the character on point, so either member of your team can earn them;
  the "Finish Arcade mode with X" achievements keep the set's "main fighter" (your first pick);
- an achievement named after a hyper combo needs that hyper for the KO (the original accepted any hyper of the
  character).

75 achievements, 575 points. Unless the goal says otherwise: Arcade mode (BATTLE in the main menu), difficulty 2
or higher.

Notes:

- The hyper achievements (23 to 44) check the move that landed the KO, read from the character's object at the
  moment the fight is won; a KO by your special partner (assist) does not count for them. Iron Body counts a win
  as Mech Zangief. Magnetic Shockave and Galaxy Energy keep the
  original rule: neither title names a move the PlayStation version has.
- Perfects need the fight won: knocking out the opponent's first character is not enough.
- "Truly Marvelous!" asked for no lost round in the original; with one round per fight that would be the same as
  "no continue", so here no character of yours may be knocked out in the whole run.

## Memory card

- Progress goes into its own save file, `BASLUS-01059ACH`, on the memory card in slot 1 or 2. It is created at the
  main menu the first time (one block) and read at later boots.
- New unlocks are written while the main menu is idle, never during a fight or in the option screens, where the
  game's own card code runs. The page's first line shows where the progress is saved, or "NO MEMORY CARD" /
  "MEMORY CARD FULL"; unlocks then wait until the card can be written.
- EX OPTIONS **ACHIEVEMENT POPUP OFF** hides the popup and its sound; unlocks are still recorded and saved.

## When they don't count

- **VERSUS CPU**: the mode stays VERSUS, so nothing unlocks.
- **INFINITE SUPER METER ON**: nothing unlocks while the row is ON.

## When they switch off

As in the other two hacks, the runtime lives in kernel RAM the BIOS leaves unused. At boot a check reads the BIOS
date: on a PS2 or PS3 (whose PS1 BIOS keeps its own tables in that memory) nothing is installed, and the
ACHIEVEMENTS item does not appear. The game then runs normally.
