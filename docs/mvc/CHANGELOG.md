# Marvel vs. Capcom Tag Team Hack: changelog

## 1.0 (2026)

First release.

- Tag battles in every Arcade and Versus match: four different, complete characters, tag with HP + HK, one life
  bar per character, red-life recovery on the bench, KO hand-over. The CPU tags at about the arcade's rate.
- Special partners (assists) in every tag battle; EX OPTIONS ASSISTS ROULETTE (default, with the arcade's button
  codes) / NORMAL / OFF.
- Onslaught playable in Versus and Arcade, with his own ending.
- Variable Cross (Duo Team Attack) with your real tag partner; the cut-in screen is skipped.
- VERSUS CPU in the main menu.
- EX OPTIONS, saved with the game's memory card save: STAGE ANIM, INTRO, ACHIEVEMENT POPUP, ASSISTS, ARCADE BALANCE,
  INFINITE SUPER METER.
- 75 built-in achievements adapted from the RetroAchievements set by SherryBirkin.
- Full sound banks for partners and assists, with a voice clarity and loudness correction.
- PS3 / PS2: achievements, assists and the VERSUS CPU row switch off automatically.
- 8 MB (with the arcade set `mvsc`): arcade animation frames, full-resolution effects and intros, characters cached
  between fights, arcade voices streamed at full quality. On 2 MB the same image plays like the 2 MB image.
- One or two players: no multitap support. Version line TAG HACK 1.0.
